第一段落（第1—5回）：序幕与总纲

第一回：甄士隐梦幻识通灵　贾雨村风尘怀闺秀

本回在脂评本中的结构作用：脂批将本回前段称为“楔子”，属全书总纲。甲戌本第一回前有凡例与楔子，各本批语集中揭示“真事隐去”“假语村言”的叙事策略。

本回可分为四个部分。

第一部分：神话缘起——石头思凡与降世因由

  • 时间：补天之时 → 茫茫大士、渺渺真人携石游历之时
  • 地点：大荒山无稽崖青埂峰 → 太虚幻境（警幻仙子处）
  • 登场人物：女娲（提及）、一僧一道（茫茫大士、渺渺真人）、顽石、绛珠仙子、神瑛侍者（贾宝玉前身）、警幻仙子（提及）
  • 主要情节：女娲补天剩一石，通灵后求僧道携入红尘。僧道携石至太虚幻境，神瑛侍者浇灌绛珠仙草，仙草愿以泪报恩。僧道携石投胎入世。

第二部分：人间引子——甄士隐的夏日一梦

  • 时间：夏日午后
  • 地点：姑苏阊门十里街仁清巷葫芦庙旁甄士隐家中
  • 登场人物：甄士隐、甄家丫鬟娇杏、一僧一道（梦中）
  • 主要情节：甄士隐午梦，遇僧道携通灵玉游历太虚幻境，欲看“蠢物”（通灵玉），未及细看被惊醒。

第三部分：人间开场——贾雨村寄居与中秋交游

  • 时间：八月十五中秋夜 → 次年正月十五 → 次年三月十五
  • 地点：葫芦庙内 → 甄士隐家 → 庙门口 → 码头
  • 登场人物：甄士隐、贾雨村、甄家丫鬟娇杏、甄士隐家童、霍启
  • 主要情节：贾雨村寄居葫芦庙，中秋夜甄士隐赠银衣助其赶考，贾雨村次日不辞而别。次年元宵英莲失踪，三月十五葫芦庙炸供失火，甄家被烧成瓦砾。

第四部分：收结与预言——甄士隐出家

  • 时间：甄家被烧后一二年
  • 地点：大如州封肃家 → 街上看“好了歌”
  • 登场人物：甄士隐、封肃、甄家娘子、跛足道人
  • 主要情节：甄士隐投奔岳父封肃，日渐贫病。一日遇跛足道人唱《好了歌》，甄士隐注解后悟道，随道人出家。

第二回：贾夫人仙逝扬州城　冷子兴演说荣国府

全回可分为三个部分。

第一部分：贾雨村娶娇杏、升迁与罢官

  • 时间：第一回之后数年（贾雨村中进士 → 升知府 → 罢官）
  • 地点：金陵（应天府）→ 贾雨村任所
  • 登场人物：贾雨村、娇杏、封肃（提及）
  • 主要情节：贾雨村中进士后升为知府，娶娇杏为二房，娇杏生子后扶正。贾雨村因“恃才侮上”被参革职，罢官后游历天下至扬州。

第二部分：贾雨村游历扬州，入林府做西宾

  • 时间：贾雨村罢官后（黛玉五岁左右）
  • 地点：扬州巡盐御史林如海府中
  • 登场人物：贾雨村、林如海、贾敏（提及）、林黛玉
  • 主要情节：贾雨村托朋友荐入林如海家，做林黛玉的家庭教师。黛玉年方五岁，母贾敏病逝后哀伤过度，连日不上学。

第三部分：冷子兴演说荣国府

  • 时间：贾敏病逝后不久
  • 地点：扬州城外智通寺门前酒肆
  • 登场人物：贾雨村、冷子兴
  • 主要情节：贾雨村遇冷子兴，冷子兴详细演说贾府世系：宁荣二府由来、贾代化、贾代善、贾母、贾赦、贾政、贾敬、贾珍、贾琏、王夫人、贾珠、李纨、贾元春、贾迎春、贾探春、贾惜春、贾宝玉（衔玉而生、抓周取脂粉）、王熙凤。贾雨村发表“正邪两赋”论。

第三回：金陵城起复贾雨村　荣国府收养林黛玉

全回可分为五个部分。

第一部分：贾雨村得林如海荐书，随黛玉进京

  • 时间：第二回谈话后不久
  • 地点：扬州林如海府 → 运河船中 → 京城
  • 登场人物：贾雨村、林如海、林黛玉、贾府派来接黛玉的人
  • 主要情节：林如海托贾雨村送黛玉进京，附有荐书。贾雨村同黛玉乘船北上，持书拜见贾政，贾政为他谋得应天府知府复职。

第二部分：黛玉入荣国府，初见贾母及众亲

  • 时间：黛玉进京当日
  • 地点：荣国府贾母正房
  • 登场人物：林黛玉、贾母、迎春、探春、惜春、邢夫人、王夫人、李纨
  • 主要情节：黛玉拜见贾母，贾母大哭。黛玉见迎春、探春、惜春。众人问其病情，黛玉说起癞头和尚要化她出家未成。

第三部分：王熙凤出场与黛玉见两位舅舅（未果）

  • 时间：紧接上文
  • 地点：贾母房中 → 贾赦院 → 贾政院
  • 登场人物：王熙凤、黛玉、贾母、邢夫人、王夫人、众丫鬟、贾赦（未露面）、贾政（未露面）
  • 主要情节：王熙凤“未见其人，先闻其声”，携黛玉夸赞。黛玉拜见贾赦，贾赦推病不见；拜见贾政，王夫人说贾政斋戒去了，嘱咐黛玉远离宝玉（“混世魔王”）。

第四部分：黛玉初见宝玉，宝玉摔玉

  • 时间：同日傍晚
  • 地点：贾母房中
  • 登场人物：林黛玉、贾宝玉、贾母、王夫人、王熙凤
  • 主要情节：宝玉还愿回来，见黛玉说“这个妹妹我曾见过的”，为黛玉取字“颦颦”。问黛玉有无玉，黛玉说没有，宝玉摘下通灵玉狠命摔去。

第五部分：安排住处，黛玉入睡

  • 时间：当天夜里
  • 地点：贾母房中碧纱橱内外
  • 登场人物：林黛玉、贾宝玉、贾母、袭人、鹦哥（紫鹃）
  • 主要情节：贾母将黛玉安置在碧纱橱里，宝玉在碧纱橱外。袭人劝黛玉不要伤心，黛玉当晚暗自垂泪。

第四回：薄命女偏逢薄命郎　葫芦僧乱判葫芦案

全回可分为三个部分。

第一部分：贾雨村上任应天府，门子献护官符

  • 时间：贾雨村复职后不久
  • 地点：应天府衙门
  • 登场人物：贾雨村、门子（原葫芦庙小沙弥）、原告、被告家人
  • 主要情节：贾雨村上任后遇薛蟠打死冯渊一案，原欲发签缉拿，被门子以目示意止住。门子递上“护官符”，详述贾、史、王、薛四大家族权势。

第二部分：门子细说英莲来历与薛蟠背景

  • 时间：紧接上文
  • 地点：应天府衙门密室
  • 登场人物：贾雨村、门子
  • 主要情节：门子告知被打死之冯渊与被拐女子英莲（甄士隐之女）的始末，以及薛蟠的背景——薛家乃金陵一霸，薛姨妈乃王夫人之胞妹，薛蟠之妹薛宝钗正待选入宫。

第三部分：贾雨村徇私判案，薛宝钗进京

  • 时间：紧接上文 → 不久后
  • 地点：应天府 → 京城荣国府
  • 登场人物：贾雨村、门子、薛蟠、薛姨妈、薛宝钗、王夫人、贾政、贾母、宝玉
  • 主要情节：贾雨村徇情枉法，判薛家赔冯家烧埋银子了事，乱判此案。薛家进京后入住荣国府梨香院，薛宝钗与贾府众人相见。

第五回：游幻境指迷十二钗　饮仙醪曲演红楼梦

脂批明确指出，第五回为全书总纲，通过宝玉梦游太虚幻境，以画册、判词及歌曲的形式，将金陵十二钗及主要人物的命运结局一一隐喻交代。全回可分为四个部分。

  • 主要情节：王夫人听信王善保家的谗言，下令抄检大观园。凤姐带人依次抄检怡红院、潇湘馆、秋爽斋、稻香村、藕香榭、缀锦楼。探春怒打王善保家的，惜春执意不要入画。晴雯“豁啷”一声将箱子掀底，凤姐称其“有本事的人”。

第二部分：司棋被逐，入画被撵

  • 时间：当日抄检完毕
  • 地点：大观园各院
  • 登场人物：司棋、潘又安、入画、惜春、尤氏
  • 主要情节：从司棋箱中搜出潘又安情书与鞋袜，司棋被逐出大观园。入画私藏哥哥东西被惜春撵出，惜春声明与宁国府断绝关系。

第七十五回：开夜宴异兆发悲音　赏中秋新词得佳谶

第一部分：宁府开夜宴，祠堂悲音

  • 时间：抄检大观园后数日
  • 地点：宁国府会芳园
  • 登场人物：贾珍、尤氏、邢德全、薛蟠、贾蓉
  • 主要情节：贾珍在会芳园开夜宴，忽闻祠堂墙下有人长叹。贾珍等毛骨悚然，次日贾珍说“可知咱们家里也太有钱了”。

第二部分：中秋赏月，众人作诗

  • 时间：八月十五中秋节
  • 地点：大观园嘉荫堂 → 凸碧山庄
  • 登场人物：贾母、贾赦、贾政、贾珍、宝玉、贾环、贾兰、黛玉、湘云
  • 主要情节：贾母中秋赏月，命人击鼓传花行令。贾政说“怕老婆”笑话，贾赦说“针灸”笑话。宝玉作诗贾政赏扇，贾环作诗贾赦赏玩物。黛玉湘云在凹晶馆联诗，联至“寒塘渡鹤影，冷月葬花魂”，妙玉出现止住。脂批“冷月葬花魂”为黛玉结局之谶。

第七十六回：凸碧堂品笛感凄清　凹晶馆联诗悲寂寞

第一部分：凸碧堂品笛

  • 时间：中秋之夜（紧接第七十五回）
  • 地点：凸碧山庄
  • 登场人物：贾母、尤氏、王夫人、邢夫人、众姊妹
  • 主要情节：贾母赏月至四更天，闻笛声凄清伤感。尤氏说笑话“一家子四个儿子”，贾母昏沉思睡。众人散去时贾母说“我也困了”。

第二部分：凹晶馆联诗

  • 时间：当夜
  • 地点：凹晶馆
  • 登场人物：林黛玉、史湘云、妙玉
  • 主要情节：黛玉湘云在凹晶馆联诗，湘云出“寒塘渡鹤影”，黛玉对“冷月葬花魂”。妙玉出来止住续联，并续完三十五韵。湘云说“果然太悲凉了”。

第七十七回：俏丫鬟抱屈夭风流　美优伶斩情归水月

第一部分：晴雯被逐，抱屈而死

  • 时间：中秋后数日
  • 地点：荣国府 → 晴雯兄嫂家
  • 登场人物：王夫人、晴雯、宝玉、袭人、麝月、秋纹、碧痕、芳官、四儿、慧娘
  • 主要情节：王夫人到怡红院，将晴雯、芳官、四儿等赶出大观园。晴雯已病四五日水米不沾，被架出去后当夜死去。宝玉偷偷去探视，晴雯咬下指甲递与宝玉，说“我死也不甘心”。晴雯死后宝玉作《芙蓉女儿诔》祭之。脂批谓“晴雯为黛玉之影”。

第二部分：芳官等出家

  • 时间：晴雯死后数日
  • 地点：水月庵
  • 登场人物：芳官、蕊官、藕官、水月庵智通、地藏庵圆信
  • 主要情节：芳官等被王夫人逐出后不愿配人，在水月庵出家为尼。

第七十八回：老学士闲征姽婳词　痴公子杜撰芙蓉诔

第一部分：贾政命宝玉作《姽婳词》

  • 时间：晴雯死后不久
  • 地点：荣国府
  • 登场人物：贾政、宝玉、贾环、贾兰、众清客
  • 主要情节：贾政命宝玉作《姽婳词》咏林四娘故事。宝玉作长篇古风，贾政“亦觉罕异”。

第二部分：宝玉作《芙蓉女儿诔》

  • 时间：同日
  • 地点：大观园芙蓉花前
  • 登场人物：贾宝玉、黛玉（后至）
  • 主要情节：宝玉在芙蓉花前焚香祭晴雯，作长篇诔文《芙蓉女儿诔》。黛玉忽至，说“茜纱窗下，我本无缘；黄土垄中，卿何薄命”，宝玉改作此句。脂批此处有夹批“观此句便知诔文实不为晴雯而作也”，直指此诔预伏黛玉之死。

第五段落（第79—80回）：收束

第七十九回：薛文龙悔娶河东狮　贾迎春误嫁中山狼

第一部分：薛蟠娶夏金桂

  • 时间：秋季（第七十八回之后）
  • 地点：薛家 → 荣国府
  • 登场人物：薛蟠、夏金桂、薛姨妈、宝钗、香菱、宝玉
  • 主要情节：薛蟠娶夏金桂，夏金桂“外具花柳之姿，内秉风雷之性”，入门后便辖制薛蟠。香菱改名秋菱。宝玉为此心中不乐，去找天齐庙疗治。

第二部分：迎春误嫁孙绍祖

  • 时间：薛蟠娶亲后不久
  • 地点：荣国府各处
  • 登场人物：贾赦、孙绍祖、贾迎春、贾母、宝玉、王夫人
  • 主要情节：贾赦将迎春许配孙绍祖，宝玉对此感到忧虑。孙绍祖家资饶富，但系“中山狼”之辈。迎春出嫁，宝玉为之悲戚。

第八十回：美香菱屈受贪夫棒　王道士胡诌妒妇方

第一部分：香菱受辱，夏金桂大闹薛家

  • 时间：迎春出嫁后
  • 地点：薛家
  • 登场人物：夏金桂、薛蟠、香菱、宝蟾、薛姨妈、宝钗
  • 主要情节：夏金桂设计陷害香菱，令薛蟠痛打香菱。薛姨妈劝解反被夏金桂顶撞，宝钗以言语压服夏金桂。香菱被薛蟠逐出，宝钗收留。

第二部分：宝玉求疗妒方

  • 时间：当日稍后
  • 地点：天齐庙
  • 登场人物：贾宝玉、王一贴（王道士）
  • 主要情节：宝玉到天齐庙，王一贴胡诌“疗妒汤”（冰糖、陈皮、梨熬水）。脂批指出此回收束全书人物命运之伏笔。

第三部分：迎春归宁哭诉，孙绍祖辱骂

  • 时间：数日后
  • 地点：荣国府
  • 登场人物：贾迎春、王夫人、宝玉
  • 主要情节：迎春归宁，向王夫人哭诉孙绍祖骂她是“醋汁子老婆拧出来的”，说贾赦使了他五千银子。此回以迎春悲剧收束前八十回，为八十回后贾府彻底败落埋下伏笔。
